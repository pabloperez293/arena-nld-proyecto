# ARENA NLD 24HS — Landing Page

1. Sitio web responsive desarrollado para presentar el gimnasio ARENA NLD 24HS y sus servicios.
2. La página comienza con un encabezado que incluye el logo institucional y un menú de navegación.
3. La sección principal presenta el gimnasio y permite acceder rápidamente a la información destacada.
4. El contenido está organizado en secciones para facilitar la navegación y la experiencia del usuario.
5. Incluye un carrusel interactivo para visualizar imágenes y conocer las instalaciones.
6. Incorpora botones de contacto y enlaces a WhatsApp para realizar consultas.
7. El diseño se adapta automáticamente a computadoras, tablets y celulares.
8. El proyecto está organizado en `index.html`, `css/styles.css`, `js/main.js` y `assets/images/`.
9. Utiliza HTML semántico, CSS, JavaScript y Tailwind CSS para lograr una interfaz moderna y funcional.
10. Para visualizarlo, se debe abrir `index.html` en el navegador, preferentemente utilizando Live Server de Visual Studio Code.
